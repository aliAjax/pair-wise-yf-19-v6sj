# hxyfront-62007 植物标本馆数字建档（纸签抄录工作流）

源提示词编号：9 · 开发端口 62007

植物标本馆压制标本的纸签转录建档前端：标本员按采集号领取待转录标本，抄录
**物种、地点、海拔、采集人、柜位**，经复核员与标签照片逐字段比对后才发号上柜。

## 业务规则

1. **按采集号领取**：队列中的待转录标本先由标本员领取，领取后进入“转录中”，其他人不能再领。
2. **录入与复核分开**：标本员和复核员分别登记姓名；同一人不能复核自己录入的标本。
3. **逐字段校录判定**：复核时对物种 / 地点 / 海拔 / 采集人逐项判定“一致 / 不符”，
   并实时检查柜位是否空闲。**校录判定（verdicts）与页面状态（status）分开存储维护**。
4. **退回保留旧版**：任一字段与标签照片不符（或柜位被占）即退回，草稿保留上一版内容，
   标本员修正后可重新提交。
5. **柜位不能先占**：录入和待复核阶段的柜位只是“意向”，不计入占用；
   占用情况只从“已馆藏”标本实时推导，全过复核时柜位才真正占用。
6. **发号锁定**：全部一致且柜位可用时发放馆藏号（`HBG-年份-序号`，序号不复用），
   并按当时的值锁定原字段。
7. **馆藏后变更**：改物种或柜位必须填写原因并重新复核；柜位变更获批后
   **原柜位暂不释放**，进入“暂留”名单，由人工确认实物搬走后再释放。
8. **本地数据共享与持久化**：队列、采集地点卡、柜位记录、详情页共用同一份
   localStorage 数据，关掉重开可继续；页面提供“重置本地数据”恢复演示种子。

## 页面

- **入库队列**：状态筛选（待转录 / 转录中 / 待复核 / 已退回 / 已馆藏）、领取、录入草稿、
  逐字段复核、退回 / 发号。
- **采集地点卡**：按地区（神农架 / 宜昌 / 恩施…）聚合小地名、海拔、物种与采集人。
- **柜位记录**：柜位图区分空闲 / 已上柜 / 调柜暂留 / 仅意向，暂留柜位可人工释放。
- **单份标本详情**：标签真值与锁定值对照、发起物种 / 柜位变更、复核变更、完整复核留痕。

## 技术栈与运行

React 19 + Vite 7 + TypeScript（strict），无后端，数据存浏览器 localStorage。

```bash
npm install
npm run dev        # http://localhost:62007
npm run typecheck  # 严格类型检查
npm run build
```
