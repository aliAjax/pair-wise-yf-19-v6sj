# 植物标本馆数字建档

纸签抄录式标本建档的前端应用：标本员按采集号领取待转录标本，录入物种、地点、海拔、采集人、柜位五个字段；录入与复核分离，全部字段与标签照片一致后才发放馆藏号并锁定。

## 业务规则

- **按采集号领取**：待领取 → 转录中（记录领取人，只有领取人可改录）；草稿随本地数据持久化，关闭重开可继续。
- **录入与复核分离**：提交后进入待复核；复核人不能是录入人本人；复核界面逐字段对照标签照片判定（自动初判可人工改判）。
- **任一不符即退回**：五项判定中有一项"不符"即退回，当前转录稿原样保留并展示上次退回意见，不发馆藏号。
- **柜位不能先占**：待复核期间柜位仍为空闲，占用只在五字段一致、复核通过的瞬间登记；若该柜已被他人建档占用，阻断发证。
- **建档锁定**：通过后发放自增馆藏号（HN-0001…），锁定五字段并留版本 v1。
- **建档后变更**：改物种或柜位必须填写原因并重新复核；审核期间**原柜位不释放、新柜位不预占**（柜位记录中标"迁出审核中 / 拟调入"）；通过才换锁并生成新版本，驳回则维持旧版。
- **共用本地数据**：转录队列、采集地点信息卡、馆藏柜位记录、标本详情共用同一份 localStorage 数据。
- **判定与页面状态分离**：校录判定、版本、变更申请随领域数据持久化；标签页、筛选条件、表单展开等界面状态只在内存中。

## 页面

- **转录队列**：按状态筛选（待领取 / 转录中 / 待复核 / 复核退回 / 变更待复核 / 已建档）、关键字搜索，点击进入详情。
- **单份标本详情**：标签照片、转录稿、逐字段复核表、锁定字段、变更申请与复核、版本与复核留痕时间线。
- **采集地点信息卡**：已建档按锁定值聚合，未建档按纸签聚合。
- **馆藏柜位记录**：A/B/C 三区柜格，占用 / 迁出审核中 / 拟调入 / 空闲四种状态。

## 技术栈

React 19 + Vite 7 + TypeScript（严格模式），无后端，数据存于浏览器 `localStorage`。

```bash
npm install
npm run dev              # http://localhost:62007
npm run build            # tsc 严格类型检查 + 生产构建
npm run typecheck
npm run test:invariants  # 业务不变量冒烟测试（node）
```

## 代码结构

- `src/types.ts` — 领域模型（标本、转录稿、复核判定、变更申请、版本）
- `src/store/seed.ts` — 演示种子数据与 localStorage 读写
- `src/store/logic.ts` — 纯函数业务规则（领取/转录/复核/变更、柜位登记、地点聚合）
- `src/store/store.tsx` — React Context，接线动作与持久化
- `src/components/` — 队列、详情、转录、复核、地点卡、柜位记录、标签照片
